# ShantText

Static website supplied as `index.html`. The original design and content are preserved in `public/index.html`.

## Render settings

- Service type: Static Site
- Branch: `main`
- Build command: `true`
- Publish directory: `public`

No dependencies, backend, or environment variables are required. Fonts load from Google Fonts.

## Local preview

Run `python3 -m http.server 8000 --directory public` from this directory, then open http://localhost:8000.
